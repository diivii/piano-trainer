# Piano Trainer: notes for Claude

Personal piano practice web app. Reads a digital piano (Kawai CN201) over Web MIDI,
shows MusicXML sheet music (OpenSheetMusicDisplay) and follows along as you play.
Main target is an **iPad in the "Web MIDI Browser" app** (Safari has no Web MIDI);
desktop Chrome/Edge is used for development.

Live: https://diivii.github.io/piano-trainer/

`README.md` has the feature list, the file-by-file layout and how deploying works.
Keep it up to date when features or files change. This file covers how to work on
the project and where it stands.

## How to work here

- Plain HTML/CSS/JS ES modules, no build step, no npm, no framework. Only dependency
  is the bundled `vendor/opensheetmusicdisplay.min.js`.
- Run locally: `python tools/serve.py` (or `start-server.cmd`), then http://localhost:8000.
  `.claude/launch.json` has a preview config for it.
- No automated tests. Check changes in the browser using the built-in simulator
  (computer keyboard / mouse as piano) and the MIDI event log.
- **The UI is in German** (note names C, Cis, … B, H). New UI text must be German;
  code, comments and commit messages are English.
- `js/midi-input.js` is the only module that touches Web MIDI. Everything else gets
  normalized note events, so a native app later would only replace that file.
- Practice logic (`practice.js`, `tempo-practice.js`) has no display code; keep it that way.
- Data lives in the browser's IndexedDB on the device (`storage.js`). Keep the backup
  format (`backup.js`) backwards compatible so old backups can still be restored.
- **Pushing to `main` publishes the live site** via GitHub Actions
  (`.github/workflows/pages.yml`). Only push when the user asks.
- Built-in samples are generated by `tools/make_samples.py`; edit that script and
  re-run it rather than editing `samples/*.musicxml` by hand.

## Current status (2026-10-20)

All built on 2026-10-19:

- Done: library with per-piece stats, sheet music import (`.musicxml`/`.xml`/`.mxl`),
  wait mode, tempo mode with metronome and timing judgement, colored notes, hands
  separately, bar loops, key hints, run history, backup/restore, focus mode / note zoom,
  7 built-in sample pieces, German UI, "Anhören" (playback via MIDI out or Web Audio),
  versioned loading so the iPad always gets the latest deploy.
- Done: MIDI on the iPad works in the Web MIDI Browser (confirmed 2026-10-20). It
  needed workarounds for that app's Web MIDI polyfill in `midi-input.js`: old-style
  iterators, continuous device polling, ignoring the add-on's callback errors.
  Keep them when changing MIDI code.
- No known TODOs in the code.
